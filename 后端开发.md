# Medical-Graph-RAG 后端开发文档

## 1. 架构

```
backend/
├── app.py            # FastAPI 路由注册
├── config.py         # Pydantic Settings（环境变量）
├── deps.py           # 依赖注入（单例）
├── schemas.py        # Request/Response Pydantic 模型
└── services/
    ├── graph_service.py      # Neo4j 图检索
    ├── llm_service.py        # LLM 调用（Qwen）
    ├── diagnosis_service.py  # 诊断编排
    ├── context_builder.py    # 图上下文格式化
    └── chain_builder.py      # 诊断证据链构建
```

### 分层职责

| 层 | 职责 | 依赖方向 |
|---|------|---------|
| `app.py` | 路由、HTTP 异常、响应 | → schemas, deps |
| `schemas.py` | 请求校验、响应序列化 | 无 |
| `deps.py` | 服务实例化、单例管理 | → config, services |
| `services/` | 业务逻辑 | → config, 外部 SDK |

## 2. Settings 配置

```python
# backend/config.py
from pydantic import Field
from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    # Neo4j
    neo4j_uri: str = Field(validation_alias="NEO4J_URI")
    neo4j_username: str = Field(validation_alias="NEO4J_USERNAME")

    # Service
    service_host: str = Field(default="0.0.0.0", validation_alias="SERVICE_HOST")
    service_port: int = Field(default=8000, validation_alias="SERVICE_PORT")

    model_config = SettingsConfigDict(env_file=(".env", "backend/.env"), case_sensitive=False, extra="ignore")
```

## 3. 依赖注入

```python
# backend/deps.py
async def get_graph_service():
    global _graph_service
    if _graph_service is None:
        from .services.graph_service import GraphService
        _graph_service = GraphService(get_settings())
    return _graph_service

async def get_llm_service():
    global _llm_service
    if _llm_service is None:
        from .services.llm_service import LlmService
        _llm_service = LlmService(get_settings())
    return _llm_service

async def get_diagnosis_service():
    global _diagnosis_service
    if _diagnosis_service is None:
        from .services.diagnosis_service import DiagnosisService
        graph_svc = await get_graph_service()
        llm_svc = await get_llm_service()
        _diagnosis_service = DiagnosisService(graph_svc, llm_svc)
    return _diagnosis_service
```

路由通过 `Depends(get_xxx_service)` 注入，FastAPI 自动处理 await。

## 4. API 路由

### 4.1 健康检查

```
GET /api/health
→ HealthResponse { status: str, neo4j: str, qwen: str }
```

检测 Neo4j 连通性（`RETURN 1`）和 Qwen API 可用性（`models.list()`）。

### 4.2 图检索

```
POST /api/graph/search
→ GraphSearchRequest {
    keywords: str,           // "糖尿病, 血糖"（逗号分隔）
    hop: int = 2,            // 1-3, 图扩展跳数
    limit: int = 30,         // 1-200, 返回节点上限
    layers: list[str] = ["bottom","middle","top"],
    reference_hops: int = 1  // 0-3, 跨层扩展跳数
  }
→ GraphSearchResponse {
    nodes: list[GraphNode],
    links: list[GraphLink],
    summary: list[SummaryItem],
    layerStats: dict[str, int]
  }
```

### 4.3 诊断建议（非流式）

```
POST /api/diagnosis/suggestions
→ DiagnosisRequest {
    patient_info: str,       // 患者主诉/病史
    keywords: str,           // 症状关键词
    top_k: int = 20,         // 图检索上限
    layers: list[str] = ["bottom","middle","top"],
    reference_hops: int = 1,
    stream: bool = false
  }
→ DiagnosisResponse {
    diagnosis_suggestions: list[DiagnosisSuggestion],
    diagnosis_chain: DiagnosisChain,
    graph_summary: list[SummaryItem],
    layer_stats: dict[str, int]
  }
```

### 4.4 诊断建议（SSE 流式）

```
POST /api/diagnosis/suggestions/stream
→ 同上 Request（stream 忽略）
→ SSE 事件流:

  data: {"type":"graph","data":{...nodes,links,summary,layerStats...}}
  data: {"type":"suggestion_chunk","data":{"delta":"{"}}
  data: {"type":"suggestion_chunk","data":{"delta":"\"diagnosis"}}
  ...
  data: {"type":"chain","data":{...nodes,links,summary...}}
  data: {"type":"done"}
```

## 5. GraphService 接口

```python
class GraphService:
    def __init__(self, settings: Settings) -> None: ...

    async def health_check(self) -> bool: ...
        # 同步 driver → asyncio.to_thread 包装

    async def search_subgraph(
        self,
        keywords: list[str],    # 关键词列表
        hop: int,               # 图扩展跳数
        limit: int,             # 返回节点上限
        layers: list[str] | None = None,   # 过滤 layer
        reference_hops: int = 0,            # 跨层扩展跳数
    ) -> dict[str, Any]: ...
        # 返回 {"nodes": [...], "links": [...], "summary": [...], "layerStats": {...}}
```

### 关键 Cypher 结构

```
// 步骤1: 种子节点匹配（关键词 + layer 过滤）
MATCH (n) WHERE ... CONTAINS AND n.layer IN $layers

// 步骤2: 图内扩展 hop 跳
OPTIONAL MATCH (s)-[*1..{hop}]-(m)

// 步骤3: 跨层扩展（通过 Summary 桥接）
OPTIONAL MATCH (bn)-[:SUMMARIZES]-(s:Summary)-[:REFERENCE]-(ref)

// 步骤4: 收集子图内关系
OPTIONAL MATCH (n)-[r]-(m) WHERE m IN graph_nodes
```

### 序列化安全

所有从 Neo4j 返回的属性值在放入 response 前经过 `json.dumps({k: v})` 预检，不可序列化的类型（DateTime 等）转为 `str(v)`。

### 跨层节点不截断

Python 侧按 `layer` 分组后交错分配 slots:
```
per_layer = max(limit // max(len(layer_nodes), 1), 2)
```
确保每层至少有一个节点返回，防止某层被 Cypher `LIMIT` 整体截断。

```python
@retry(stop=stop_after_attempt(3), wait=wait_exponential(min=1, max=10))
async def _call_llm(self, messages, **kwargs) -> str:
    response = await asyncio.wait_for(
        self._client.chat.completions.create(
            model=self._settings.qwen_model,
            messages=messages,
            **kwargs,
        ),
        timeout=30.0,
    )
    return response.choices[0].message.content or ""
```

## 9. 图数据模型

### 节点

```cypher
CREATE (n:Disease {
  id: "2型糖尿病",           -- 唯一标识（实体名 UPPERCASE）
  name: "2型糖尿病",         -- 显示名
  gid: "uuid-string",        -- 所属子图 ID
  layer: "middle",           -- 层级: bottom/middle/top
  description: "...",        -- 实体描述
  embedding: [...],          -- BGE 512-dim vector
  source: "nano_graphrag"
})

CREATE (s:Summary {
  content: "摘要文本",
  gid: "uuid-string"
})
```

### 关系类型

| 关系 | 方向 | 说明 |
|------|------|------|
| TREATS | (Treatment)→(Disease) | 治疗关系 |
| CAUSES | (Condition)→(Disease) | 病因关系 |
| HAS_SYMPTOM | (Disease)→(Symptom) | 症状关系 |
| INDICATES | (Test)→(Disease) | 诊断指示 |
| RELATED_TO | 双向 | 通用关联 |
| SUMMARIZES | (Summary)→(Node) | 摘要归属 |
| REFERENCE | (Top)→(Summary) | 跨层引用 |

### 跨层遍历路径

```
Top 层节点 ←─SUMMARIZES─ Summary ─REFERENCE─ Middle Summary ─SUMMARIZES─→ Middle 层节点
```

Cypher 中通过 `(bn)-[:SUMMARIZES]-(s:Summary)-[:REFERENCE]-(ref)` 桥接。
